# 2026-10-07 작업 일지

## 1. Google Maps 블랙스크린 현상 해결
- **증상**: 주변콜맵 진입 시 지도가 렌더링되지 않고 검정색 바탕만 표시되는 현상 발생.
- **원인**: 이전 버전에 임시로 적용되었던 구형 하이브리드 컴포지션 강제 렌더링 옵션(\useAndroidViewSurface = true\)이 최근 Flutter 엔진 업데이트와 충돌하여 \Stack\ 위젯 내부에서 마운트 실패(블랙 스크린)를 유발함.
- **수정 내용**: 
  - \main.dart\에서 \useAndroidViewSurface = true\를 삭제.
  - Google Maps 최신 렌더러(\AndroidMapRenderer.latest\)를 명시적으로 초기화하도록 변경하여 안정적인 렌더링 지원.
- **배포**: \1.1.8+110804\ 버전을 타겟으로 Shorebird 원격 패치 배포 진행.
