[fix] 자동 출근 연동 및 앱 재시작 시 퇴근 시간 유지 개선

1. 변경 항목 상세 설명
- WorkTimerProvider 싱글톤 패턴 적용 및 autoClockInIfNeeded 메서드 추가.
- main.dart의 afterLogsChanged 전역 콜백에 autoClockInIfNeeded 호출 연동.
- write_log_page.dart의 불완전한 자동 출근 로직(오버레이 예외) 삭제.
- WorkTimerProvider._loadState 로직을 수정하여, clockInStr이 없을 때(퇴근 상태)도 DB에 오늘 일자 누적 근무 시간이 있으면 화면에 불러오도록 적용.
- GEMINI.md에 work 폴더 내역 작성 규칙 추가.

2. 변경 이유 및 근거
- 기존에는 write_log_page에서만 자동 출근 로직이 작동하고 오버레이 환경을 예외 처리하여, OCR 자동등록이나 콜카드 다중/단건 등록 시 자동 출근이 작동하지 않았습니다.
- 퇴근 후 앱을 완전히 재시작하면, 오늘 누적된 근무 시간이 타이머 화면에서 무조건 초기화되는 버그가 있어 사용자 불편이 발생했습니다.
- 전역 DB 변경 콜백을 통해 어떤 경로로든 등록 시 타이머를 시작하고, 재시작 시 DB의 누적 시간을 불러오도록 개선했습니다.

3. 주의사항 또는 영향 범위
- 모든 일지 등록(수기, 스크린샷 자동 파싱, 콜카드 추가) 완료 시 전역적으로 근무 시간 타이머 연동 동작 여부 확인 필요.
