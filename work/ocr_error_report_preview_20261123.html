선택한 콜카드 인식정보를 관리자에게 전송합니다.

📌 반영된 설계 포인트

  • •메뉴 배치: 설정 화면 내 데이터 백업/복원 아래, 수수료 설정 바로 위에 프로그램 목록관리와 동일한 단일 메뉴 카드 형태로 배치 (모든 Android 사용자 노출).
  • •제외된 항목: 개발자 전용 도구 배너, 갤러리 이미지 불러오기 버튼, 우측 상단 공유/삭제 버튼 모두 제거.
  • •목록 표기 항목: 기존 콜카드 인식 로그 카드와 100% 동일 (프로그램 뱃지, 일시·성공/실패, 총요금, 출발지, 경유지, 도착지, 에러, RAW OCR 텍스트 펼치기).
  • •제보등록 버튼 위치: 좁은 단말기 해상도에서도 헤더 텍스트가 잘리지 않도록 각 카드 하단 우측 끝(RAW OCR 텍스트 보기 맞은편)에 배치. 전송 완료 시 제보완료 ✓로 비활성화되어 중복 전송 방지.
  • •동작 (A안): 제보등록 클릭 → 확인 팝업(선택 메모 1줄 포함) → 기존 고객지원 (이메일 문의) GAS 웹훅으로 관리자 메일 직접 발송.
  • •Shorebird 원격 패치 호환: 신규 아이콘을 추가하지 않고 기존 앱 아이콘만 재사용하므로 Dart 원격 패치 즉시 가능.
