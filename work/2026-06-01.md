## 2. 앱 설정 및 디버그 페이지 UI/UX 개선
- **설정 메뉴**: `settings_page.dart`에서 '콜카드 인식 로그' 버튼이 단독으로 떠있던 문제를 수정하여 '디버그 및 로그' 그룹 안에 통합.
- **디버그 로그 화면 (`ocr_debug_page.dart`)**:
  - 기존 갤러리 다중선택 버튼의 문구를 직관적으로 변경.
  - 로그 목록 항목에 **인식된 날짜 및 시간**을 명확히 표기.
  - 불필요한 우측 상단 복사/공유 버튼 2개를 제거하고 **로그 전체 삭제(휴지통) 버튼** 추가. (Tree-shaking으로 인한 Shorebird 폰트 에셋 변경 오류를 막기 위해 기존 아이콘들은 화면 뒷단 `Offstage`에 숨김 처리).
  - 단말기 용량 관리를 위해 **1주일이 지난 오래된 OCR 로그를 자동으로 삭제**하는 TTL 로직을 `OcrParseLogService`에 추가.

## 4. Shorebird APK 빌드 버전 불일치(Mismatch) 해결
- **이슈**: Shorebird 빌드 시 pubspec.yaml의 빌드 번호와 uild.gradle.kts가 강제로 변환한 AAB 버전 코드(예: 100704)가 불일치하여 APK 검증 및 추출이 실패하는 문제 발생.
- **해결 방안**:
  - uild.gradle.kts의 monotonicVersionCode 함수 제거 및 lutter.versionCode 직결합.
  - 	ool/bump_pubspec_version.dart를 수정하여 pubspec.yaml 자체에 단조 증가(monotonic) 버전 코드가 직접 저장되도록 변경 (예: 1.0.07+4 -> 1.0.07+100705).
  - Shorebird와 Android 플랫폼 간의 버전 정보 동기화 완료.
