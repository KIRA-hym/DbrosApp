# 2026년 8월 12일 작업 일지

## 1. 작업 개요 (로지콜마너 요금)
- **이슈**: 로지콜마너 콜카드 파싱 중, 후불과 업체지원이 분리된 법인콜에서 요금 파싱 오류 발생 (55,000원을 45,000원으로 잘못 추출).
- **목표**: 기존 파싱 로직 및 정규식을 유지한 상태로, 해당 케이스와 같이 상단 단독 안내 요금 또는 흩어진 법인 요금을 추출하는 방어 로직 추가.

## 2. 작업 내용 (로지콜마너 요금)
- lib/utils/logi_colmanner_ocr.dart 내 _parseFare() 함수 수정:
  - 콜마너 파싱 로직(colmanner == true)에 영향을 주지 않도록 !colmanner 전용 블록 내부 최상단에 보완 로직 배치.
  - **보완 A**: 안내와 남음 사이에 등장하는 큰 글씨 요금을 추출하는 정규식 추가.
  - **보완 B**: 후불과 업체지원/수동입금이 서로 떨어져 있을 때 전체 텍스트에서 금액을 독립적으로 추출 후 합산(Cross-validation)하는 로직 추가.

## 3. 작업 개요 (콜마너 주소 꼬임 방어)
- **이슈**: 콜마너의 2단 레이아웃이 OCR 상하로 무너지면서, 도착지, 출발지 라벨이 먼저 뭉쳐서 나오고 실제 주소인 경기 고양시... 와 경기 안양시... 가 한참 뒤에 연달아 나오는 기형적 구조에서 파싱 완전 실패.
- **목표**: 콜마너의 다른 주소 파싱에 영향을 주지 않으면서 이 특수 기형 구조를 잡아내는 가드(Guard) 로직 추가 및 사용자가 원하는 포맷(광역주소 + 상세주소)으로 맵핑.

## 4. 작업 내용 (콜마너 주소 꼬임 방어)
- _splitAddressText 내에 **보완 로직 C** 추가:
  - 라벨 사이에 광역지명이 없고 뒤에 광역지명 2개가 연달아 나오는 구조 탐지.
  - 뒤엉킨 텍스트를 광역주소 본문 + 상세명 형태로 합쳐서 리턴.
  - **추가 보완**: 도착지 주소 뒤에 찌부러진 레이아웃 때문에 붙어온 콜마너 메타 키워드(요라, 정장) 등)를 쪼개어 깨끗하게 절삭.
- _parseColmannerLocations 함수 내부의 조기 탈출(버그) 수정:
  - 기형 구조에서 고객정보, 입금합계 등의 UI 텍스트가 주소보다 위에 섞여서 나타날 때 주소 파싱 루프가 강제로 잘리던 현상 수정.
  - 출발지/도착지 라벨이 파싱 도중 미리 지워지지 않도록 정규식 완화.

## 5. 테스트 및 검증 결과
- **결과**: 로지콜마너 요금 검증 성공 (55,000원) 및 콜마너 주소 꼬임 검증 성공 (출발지: 경기 고양시일산동구 장항동 장항제2공영주차장입구, 도착지: 경기 안양시만안구 석수동 안양관악역).
