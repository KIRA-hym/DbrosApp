## 2. 수행 작업 내역 (프리미엄 전환 극대화 및 화면 캡처 자동등록 전면 배치 A·B·C 단계)

### 작업 A — 홈 화면(`lib/screens/home_page.dart`) 개편
1. **좌측 상단 사용자 프로필 좌측 상단 모서리 프리미엄 왕관 뱃지 오버레이**
   - `leadingWidth: padding + 40` 등 기존 AppBar 레이아웃 치수를 100% 그대로 유지하여 레이아웃 밀림 0% 보장.
   - `SettingsService.isPremiumUserNotifier`를 실시간 구독하여 프리미엄 구독자인 경우에만 프로필 아이콘 좌측 상단(`Positioned(left: -2, top: -2)`)에 골드 원형 왕관 뱃지(`Icons.workspace_premium`) 표시.
2. **홈 화면 중앙 `화면 캡처 자동등록 ON/OFF 상태 바` 배치**
   - `[대기비용 계산 / 주변 콜맵]` 행과 `[콜카드 단건등록 / 콜카드 다중등록]` 행 사이에 직관적인 상태 바(`_buildAutoCaptureStatusBar`) 추가.
   - **꺼짐(`OFF`) 상태**: 골드 테두리 + 빨간 `[꺼짐]` 배지 + `"운전 중엔 캡처만 하세요! 저절로 기록됩니다"` + 우측 `[켜기 >]` 버튼(클릭 시 3단계 시각 가이드 및 활성화 팝업 호출).
   - **켜짐(`ON`) 상태**: 초록 테두리 + 초록 `[작동중]` 배지 + `"콜 화면을 캡처하면 자동으로 일지가 저장됩니다"` + 우측 `[설정 >]` 버튼(클릭 시 설정 탭으로 이동).

### 작업 B — 3단계 시각 가이드 팝업 & `[출근]` 루틴 연동 (`lib/screens/home_page.dart`)
1. **`HomePage.showAutoCaptureGuideOrEnable` (3단계 시각 가이드 & 활성화 팝업)**
   - `STEP 1: 📸 콜 잡고 화면 캡처 (찰칵!)`
   - `STEP 2: 🔍 요금 · 출발지 · 도착지 자동 분석`
   - `STEP 3: ✅ 앱 안 켜도 운행일지 자동 저장!`
   - 하단 3버튼 하이브리드 액션:
     - `👑 하루 이용료 100원! 광고 없이\n무제한 사용하기 (프리미엄 구독)` ➔ `PaywallPage` 이동 후 구독 완료 시 미디어 권한 확인 및 자동 활성화
     - `📺 30초 광고 보고 2시간만 사용하기` ➔ 보상형 광고 시청 후 2시간 패스 부여 및 미디어 권한 확인 후 자동 활성화
     - `닫기`
2. **`_handleClockIn` 출근 루틴 연동**
   - 기존 근무 이어하기/초기화 확인(`출근 확인`) 로직을 100% 보존.
   - `화면 캡처 자동등록`이 꺼져 있고 잠금 해제되지 않은 상태에서 `[출근]`을 누르면 `오늘 운행 출근 준비` 팝업을 띄워 원클릭으로 자동 캡처를 켜고 출근할 수 있도록 연동(어떤 버튼을 선택하든 출근 타이머는 누락 없이 즉시 시작).

### 작업 C — 수기 저장 직후 1줄 체감 넛지 스낵바 (`lib/screens/write_log_page.dart`)
- 수기(직접 입력)로 신규 일지를 저장한 직후, `화면 캡처 자동등록`이 꺼져 있는 경우 골드 테두리 플로팅 스낵바 노출:
  - 문구: `"💡 직접 입력하느라 수고하셨습니다!\n[자동 캡처]를 켜두면 다음 콜부터는 캡처 한 번으로 자동 등록됩니다."`
  - 우측 `[켜기 >]` 액션 버튼 클릭 시 현재 화면 위에서 즉시 `HomePage.showAutoCaptureGuideOrEnable` 3단계 가이드 및 활성화 팝업 호출.
