# 2026-07-09 작업 내역

## 1. 자동스샷 일지 저장 기능 개선
- 금액을 인식하지 못하더라도 프로그램, 출발지, 도착지를 정상 인식한 경우에는 일지가 자동 저장되도록 요금 확인 조건을 비활성화 처리.

## 2. 출퇴근 시간 자동 재개 문제 해결
- 퇴근 후 시간이 멈춰 있는 상태에서 운행일지를 신규 등록하거나 기존 일지를 수정하더라도, 자동으로 타이머가 재개되지 않도록(퇴근 상태가 유지되도록) 로직 수정.

## 3. 홈 화면 뒤로가기 시 앱 종료 확인 기능 추가
- 메인 화면에서 뒤로가기 버튼을 눌렀을 때 바로 종료되지 않고 확인 팝업을 띄워 선택에 따라 앱을 정상 종료하도록 처리.
