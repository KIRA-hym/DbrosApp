### [fix] 일지 수정 화면에서 출발지·도착지 주소 변경 시 좌표가 갱신되지 않는 버그 및 지도 선택·지오코딩 개선
- **원인**:
  1. `write_log_page.dart`에서 기존 일지를 수정할 때 주소(`_startLocCon`, `_endLocCon`)를 다시 입력해도 기존 좌표(`_startLat/_startLng`, `_endLat/_endLng`)가 초기화되지 않고 유지되어, 저장 시 `db_helper.dart`가 새 주소로 좌표를 재조회하지 않고 기존 잘못된 좌표를 그대로 덮어쓰는 문제 발생.
  2. 주소를 다시 입력한 뒤 우측 `[핀 아이콘]`을 눌러도 옛 좌표(`initialLatLng`)가 그대로 전달되고, `location_pick_map_page.dart`의 `_bootstrap()`이 `initialLatLng != null`일 때 즉시 `return`하여 새로 입력한 주소를 검색하지 않는 문제 발생.
  3. `db_helper.dart`의 `insertOrUpdateDriveLog(row)`에서 새로 추출한 좌표를 원본 `row`에 역반영하지 않아 `logSharedCallPoint()`에 좌표가 누락되는 문제 및 `geocoding_utils.dart`에서 `normalizeAddressForGeocode()` 미적용 문제 확인.
- **변경 파일 및 상세 내용**:
  1. `lib/screens/write_log_page.dart`:
     - 좌표가 확정된 기준 주소(`_coordBoundStartLoc`, `_coordBoundEndLoc`)를 관리하고, 출발지·도착지 주소가 변경되면 기존 좌표를 즉시 `null`로 초기화하여 저장 시 및 핀 버튼 클릭 시 새 주소 기준으로 좌표가 갱신되도록 수정.
     - 주소 수정으로 인해 좌표가 초기화된 상태에서는 오해 소지가 있는 빨간 경고 아이콘이 표시되지 않도록 조건 보완.
  2. `lib/screens/location_pick_map_page.dart`:
     - 지도 진입 시 상단 검색창에 현재 주소를 자동 입력하고, 초기 검색(`_bootstrap`)과 수동 검색(`_runSearch`) 모두 `GeocodingUtils.getCoordinateFromAddressFallback()`을 사용하도록 통일.
  3. `lib/services/db_helper.dart`:
     - `insertOrUpdateDriveLog(row)`에서 새로 지오코딩된 좌표를 원본 `row` 맵에도 역반영하여 `logSharedCallPoint` 공유 데이터에도 정확한 새 좌표가 전달되도록 수정.
  4. `lib/utils/geocoding_utils.dart`:
     - `normalizeAddressForGeocode()` 정제 및 도로명/번지 숫자를 보존한 다단계 폴백 지오코딩을 적용하여 좌표 변환 성공률 향상.

### [fix] 티맵 「운행 상세 정보」 화면에서 출발/도착 라벨 세로 분리 시 출발지가 도착지로 오분류되고 '실수익' 노이즈가 남는 버그 수정
- **백업(복원 지점) 커밋 해시**: `cdd4223`
- **원인**:
  1. `TmapTripDetailOcr._parseAddresses()`에서 `출발`과 `도착` 라벨이 연달아(`출발\n도착`) 인식될 때 `startAddress`는 빈 문자열(`""`)이 되고, `도착~실수익` 사이에 위치한 실제 출발지(`서울 서초구 방배동 니나노 분식`)가 `endAddress`에 잘못 들어가는 현상 발생.
  2. 이어지는 정규식 폴백에서 정확한 출발지(`startCand`)와 도착지(`endCand`: `경기 안양시 동안구 평촌동 경기 안양시 동안구 부림로 34`)를 찾았으나, `if (endAddress.isEmpty)` 조건 때문에 이미 잘못 채워진 `endAddress`가 유지되고 실제 도착지가 버려짐.
  3. `cleanNoise()` 및 `cleanAddr()`에서 요금 숫자(`25,600P`) 뒤쪽만 지우고 앞의 `'실수익'` 키워드를 제거하지 않아 출발지 끝에 `'실수익'`이 남음.
- **변경 파일 및 상세 내용**:
  1. `lib/utils/tmap_trip_detail_ocr.dart`:
     - `_parseAddresses()`: `출발~도착` 사이가 비어 있는 경우(2단 레이아웃 라벨 연속 인식) `endAddress`에 출발지가 잘못 선점되지 않도록 `('', '')` 반환 처리.
     - `_parseInProgressCardAddresses()`: 「운행 상세 정보」 영수증 화면(`운행번호`/`운행일자`/`보험종류` 포함 및 콜카드 구분선 미포함)에서는 운행중 콜카드 전용 파서를 건너뛰어 숫자/시각이 상호명으로 합쳐지지 않도록 방어.
     - 정규식 폴백 및 `cleanNoise()` / `cleanAddr()`: `'실수익'` 및 `'보험사'` 키워드 이후 노이즈 제거 규칙 추가, 앞 단계에서 한쪽만 중복 채워진 경우 `startCand`/`endCand` 세트로 덮어쓰도록 보강.
  2. `test/ocr_test_data/tmap_seocho_anyang_case.txt`, `test/ocr_test_data/README.md`, `test/ocr_regression_test.dart`:
     - 제보받은 티맵 OCR 원문을 회귀 테스트 데이터로 영구 보관 및 테스트 케이스 추가 (전체 회귀 테스트 통과 확인).
