### 2. 관리자 웹 & 앱 AI 일괄 자동 검수 기능 핫픽스 (오류 3건 해결)
- **오류 1: Remote Config 400 INVALID_ARGUMENT 및 키 인식 불가**
  - **원인:** 웹(DbrosAdmin)의 Firebase 초기화 시 더미 appId가 들어가 있었고, 키 이름이 geminiApiKey로 잘못 호출됨.
  - **해결:** irebase_options.dart에서 실제 Web AppId와 ApiKey를 추출해 주입하고, 키 이름을 gemini_api_key로 수정.
- **오류 2: Gemini API HTTP 404 (Not Found)**
  - **원인:** 구글이 gemini-1.5-flash 모델 주소를 내리고 통합함. 또한 웹(React)에서 공식 SDK 사용 시 CORS 보안 문제 발생.
  - **해결:** 웹/앱 모두 통신 엔드포인트를 gemini-flash-latest로 업데이트. 웹은 공식 SDK를 걷어내고 순수 HTTP Fetch로 변경.
- **오류 3: Gemini API HTTP 429 (Too Many Requests)**
  - **원인:** 구글 Gemini 무료 티어의 분당 요청 제한(15 RPM)을 초과해 50개의 요청이 연달아 발송됨.
  - **해결:** 웹과 앱의 반복문(for) 내부에 1건 처리 시마다 4.1초 대기(Delay) 로직 추가하여 15 RPM 우회 방어 완료.
