1기획 의도 · 용어 통일(「프리미엄」) · 수익화 전략

앱 내 모든 배지·버튼·모달·안내 문구에서 영문 표기 대신 「프리미엄」 / 「프리미엄 전용」으로 통일합니다. DbrosAdmin에 구축된 상권/단가 분석 콜포인트맵을 광고로 열 수 없는 100% 프리미엄 전용 기능으로 홈 화면 최상단 버튼 라인에 배치하여, 구독 전환의 결정적 명분(킬러 기능)을 제공합니다.

역할 분리 핵심:
• 기존 [주변 콜맵] = 내 기록·대기/화장실·현장 위치 확인 지도 (광고 1회 해제 유지)
• 신규 [🔥 콜포인트 (프리미엄)] = 시간대·고단가(3만↑/5만↑)·핫스팟 TOP 15·플랫폼 단가 분석 빅데이터 맵 (프리미엄 전용 · 광고 불가)

2단말기 해상도 · 폴더블 · 큰 글꼴 대응 UI/UX 설계

대리운전 기사님 단말기는 보급형 소형폰(320~360dp) · 일반 스마트폰(360~430dp) · 갤럭시 Z 폴드 펼침/태블릿(600dp↑)까지 폭이 매우 넓고, 야간 운행 특성상 시스템 글꼴 확대 + 앱 내 FontSizeService 확대 사용자 비중이 매우 높습니다. 기존 앱의 ResponsiveLayout(600dp 브레이크포인트)과 FontSizeService를 그대로 확장해 아래 5대 반응형 규칙을 적용합니다.

🛡️ 텍스트 잘림·오버플로우 원천 차단 4종 장치

  • DraggableScrollableSheet: 기기 세로 길이가 짧아도(640dp) 길어도(930dp) 고정 px 대신 화면 비율로 지도/시트 균형 유지
  • LayoutBuilder + textScaler 분기: KPI 4열 ↔ 2×2 자동 전환으로 숫자(4.2만, 78%) 뭉개짐 0%
  • 배지/지도 오버레이 TextScaler.clamp(0.9, 1.2): 큰 글꼴 1.5x에서도 지도 플로팅 버튼·프리미엄 배지가 화면을 가리지 않도록 보호
  • SafeArea + viewPadding.bottom: 펀치홀·제스처 바·3버튼 내비게이션 단말기별 하단 겹침 차단

👆 운전 대기 중 한 손 조작(Thumb Zone) 최적화

  • 주요 탐색(핫스팟 TOP / 시간·플랫폼 / 콜 목록)을 화면 하단 시트에 배치해 엄지손가락 하나로 즉시 조작
  • 지도 위에서 상권을 보고 싶을 땐 시트를 아래로 쓱 내리거나 [필터 접기 ▲] 한 번으로 지도를 75% 이상 확대
  • 내 위치 반경 토글(전체/3km/10km/15km)로 현장에서 필요한 콜만 한 번에 필터링
