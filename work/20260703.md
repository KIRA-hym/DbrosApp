## 4. 광고 리워드 만료 시간 단축 및 실시간 알림 정리 기능 추가
- **settings_service.dart**: 광고 리워드 유지 시간을 3시간에서 2시간으로 단축하고, 앱 실행 시 백그라운드 타이머(_adRewardTimer)를 구동하여 2시간 만료 시 이벤트를 발생시키도록 변경.
- **main.dart**: 설정 서비스의 타이머 만료 이벤트를 수신하는 리스너를 등록하고, 만료 즉시 TodayStatsNotificationService.cancel() 과 ScreenshotAutoRegisterService.syncWithSettingsPreference() 를 호출하여 사용자 알림창과 백그라운드 캡처 감지 권한을 즉시 회수하도록 구현.

## 5. 프리미엄 안내 팝업 문구 개선
- **pro_feature_guard.dart**: 무료 횟수가 없는 기능(다중 인식, 통계)에 진입 시 '무료 횟수를 모두 사용했습니다' 대신 '프리미엄 기능 안내: 해당 기능은 동영상 광고 시청 시 1회 이용하실 수 있습니다.'로 자연스럽게 표시되도록 개선.
- **settings_page.dart**: 팝업 내 광고 시청 리워드 텍스트를 '3시간'에서 '2시간'으로 정정.
