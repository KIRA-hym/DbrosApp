## 2. 🛡️ 단건/다건 갤러리 등록 시 빈 일지 저장 차단
- **파일**: `lib/screens/single_call_card_page.dart`, `lib/screens/multi_call_card_page.dart`
- **내용**: 
  - 기존에는 자동 감지(`screenshot_auto`)에서만 사용되던 유효성 검사 `CallCardOcrParseService.isValidForAutoSave` 로직을 갤러리를 통한 수동 등록(단건/다건) 화면에도 동일하게 적용.
  - 요금 미인식, 출발지/도착지 누락, 프로그램 미식별 등 유효하지 않은 쓰레기 데이터는 DB에 저장되지 않고 '등록 실패' 건수로 처리되도록 로직 수정.
  - 다건/단건 저장 시 자체 `insert` 쿼리를 사용하던 부분을 `CallCardOcrParseService.saveLogToDatabase` 통합 메서드를 호출하도록 리팩토링하여 중복 체크 로직을 일원화함.

## 3. ⏱️ 캡처 이미지 중복 저장 쿼리 조건 변경
- **파일**: `lib/services/call_card_ocr_parse_service.dart`
- **내용**: `saveLogToDatabase` 메서드의 중복 판별 쿼리 보완.
  - 기존: `created_at > 2시간 전` (2시간 후면 동일 이미지를 다시 올려도 중복으로 걸러지지 않음)
  - **변경**: `drive_date = ?` 조건으로 변경하여, 동일한 운행일자(drive_date), 요금, 출발지, 도착지, 프로그램 정보를 가진 일지는 시간에 구애받지 않고 **중복 저장되지 않도록 완벽하게 차단**.

## 4. ⌨️ 수기 입력 화면 키패드 깜빡임(사라짐) 버그 해결
- **파일**: `lib/screens/write_log_page.dart`
- **내용**: 특정 단말기에서 입력칸 터치 시 안드로이드 키보드가 올라오다가 번쩍하고 사라져 입력이 불가하던 심각한 버그 수정.
  - 원인: 텍스트 필드 포커스 시점으로부터 300ms 후에 강제로 화면 중심부로 스크롤을 튀게 만드는 `_setupFocusScroll` 안의 `Scrollable.ensureVisible` 로직이 안드로이드 순정 키보드 애니메이션과 충돌함.
  - 해결: 해당 강제 스크롤 로직(`_setupFocusScroll`) 및 리스너 등록부를 완전히 제거하여, Flutter가 제공하는 순정 뷰포트 조절 기능(`resizeToAvoidBottomInset`)만 부드럽게 작동하도록 원상복구함.
