5
여백(Padding) — 비표준 수치 혼재 (낮은 우선순위)
표준 16/20px 체계 밖의 6px, 10px 등 미세 수치가 일부 화면에 혼재
⚠ 현재 — 비표준 수치
// write_log_page.dart 퀵패널 footer EdgeInsets.fromLTRB( isTablet ? 12.0 : 8.0, isTablet ? 8.0 : 6.0, // 6px! isTablet ? 12.0 : 8.0, isTablet ? 10.0 : 8.0, // 10px! ) // home_page.dart YouTube 섹션 SizedBox(height: isTablet ? 8 : 6) // 6px SizedBox(width: isTablet ? 12 : 10) // 10px // settings_page.dart _buildVersionInfoSection vertical: padding * 0.75 // 16 × 0.75 = 12px
✅ 개선 후 — AppSpacing 상수화
// lib/constants/app_spacing.dart (신규) class AppSpacing { static const xs = 4.0; static const sm = 8.0; static const md = 16.0; static const lg = 20.0; static const xl = 24.0; } // 사용 예 EdgeInsets.all(AppSpacing.sm) // 8px SizedBox(height: AppSpacing.xs) // 4px
📊
종합 개선 우선순위 요약
우선순위 개선 항목 수정 난이도 영향 범위 추천 접근법
🔴 높음 AppBar 타이틀 색상 (2개 화면) ⭐ 매우 쉬움 2개 파일 color: Colors.white → Color(0xFFFFC700)
🔴 높음 수입 색상 혼용 → AppColors 상수파일 ⭐⭐ 쉬움 전체 화면 app_colors.dart 생성 후 일괄 치환
🟡 중간 AppEmptyState 위젯 추출 ⭐⭐⭐ 보통 4+ 화면 single/multi_call_card에서 추출 후 통일
🟡 중간 write_log_page BorderedSection 재사용 ⭐ 매우 쉬움 1개 파일 BoxDecoration → BorderedSection.decoration()
🟢 낮음 AppSpacing 상수화 ⭐⭐ 쉬움 전체 화면 app_spacing.dart 생성 (점진적 적용)
결론: 전반적으로 디자인 일관성은 높은 편입니다. 위 5가지 개선점 중 가장 즉각적으로 보이는 변화는 ①AppBar 타이틀 색상 통일과 ②수입 색상 통일입니다. 코드 1~2줄 수정으로 시각적 일관성이 크게 향상됩니다.
