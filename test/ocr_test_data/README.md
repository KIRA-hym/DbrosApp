# OCR Test Data

이 폴더는 사용자로부터 제보받은 실제 OCR 인식 원문 로그를 모아두는 곳입니다.
향후 파싱 로직(정규식, 룰 엔진 등)을 변경할 때 기존 케이스들이 깨지지 않는지(회귀 버그) 테스트하기 위한 용도로 사용됩니다.

## 케이스 목록
- `logi_155000_case.txt`: 로지 콜카드 155,000원. "접수운행"으로 찍혀서 "배차" 단어가 없고, 도착지 주소 뒤에 "1:26대기-" 잡음이 섞였으며 출발지에 "특이사항입" 잡음이 섞임. 요금이 큰 경우 수수료(31,000)가 상한선에 걸려 오인식되는 문제 테스트.
- `tmap_seocho_anyang_case.txt`: 티맵 「운행 상세 정보」 영수증 화면 25,600원. 좌측 라벨('출발', '도착')이 연속 인식되어 출발지가 도착지로 잘못 선점되고 출발지 끝에 '실수익' 노이즈가 남는 문제 테스트. (기대값: 출발지 '서울 서초구 방배동 니나노 분식', 도착지 '경기 안양시 동안구 평촌동 경기 안양시 동안구 부림로 34', 요금 25,600)
