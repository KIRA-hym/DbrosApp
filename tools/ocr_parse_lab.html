콜카드 OCR 파싱 실험실

앱 OCR 디버그에서 복사한 원문 → 앱과 동일 Dart 파서로 PC에서 즉시 확인

웹이 계속 실패하면 → tools\parse_ocr_simple.bat (서버 없음, ocr_input.txt에 붙여넣기)
웹 사용 시 (서버 + WORKER 창 2개 필요)
1. tools\start_ocr_parse_lab.bat → 창 2개 유지 (WORKER + SERVER)
2. 브라우저: http://127.0.0.1:28765/ — /health 에 "worker":true 확인
   문제 시: tools\stop_ocr_parse_lab.bat 후 다시 시작
   ※ HTML 파일만 더블클릭하면 연결 안 됨 (별도 주소 없음)
3. OCR 원문 붙여넣기 → 파싱 실행 → 피드백용 복사
첫 파싱은 flutter test 기동으로 10~30초 걸릴 수 있습니다.
