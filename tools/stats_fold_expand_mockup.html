B — 가로 간격 공식 및 검증선
헤더·본문 두 줄 모두 같은 Row 패턴입니다: Expanded(flex:5) + SizedBox(width: gapMd) + Expanded(flex:11). 따라서 「수익 분석」(우측 col11 내부 Align.centerLeft) 과 아래 차트 Column(같은 col11) 의 열 왼쪽 끝 이 일치합니다. 카드 안 분홍 점선은 left: calc((100% - gapMd) * 5/16 + gapMd) 로 두 줄에 공통 적용되어, flex:11 시작 위치와 화면에서 겹치는지 확인할 수 있습니다.
차트 패널 안쪽 여백
_buildChartPanel → BorderedSection(padding: EdgeInsets.all(12)). 패널 테두리 기준 안쪽 제목 라인은 열 시작보다 12px 오른쪽입니다. 청색 세로 점선은 그 오프셋을 상기용입니다.
A — 접힘
기간 버튼 → SizedBox(cardGap) → 헤더 → SizedBox(gapMd) → 그리드(gap=cardGap) → SizedBox(16) 수익 분석 → SizedBox(12) → 차트 영역. 「수익 분석」은 전체 폭 대비 Align.centerLeft(차트 패널과 같은 body 좌우 패딩).
태블릿일 때 변수 (참고)

body padding 24, gapMd 20 등으로 바뀝니다. HTML에서는 :root 의 --pad-body, --gapMd 만 바꾸면 같은 구조를 재현할 수 있습니다.
