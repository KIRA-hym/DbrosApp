스크린샷 콜카드 자동등록

Android · 앱 생존(백그라운드) 중 · 오버레이/퀵패널 데이터 없음

동작 순서

1스크린샷 감지 (screenshot_callback)
2800ms 대기 후 갤러리 최신 이미지 (photo_manager)
3동일 경로 15초 디바운스
4ML Kit OCR + 기존 콜카드 파서
5요금·출발지·도착지 모두 파싱된 경우만 DB 저장 (운행시간 없으면 현재 시각)
6로컬 알림: 「운행일지 자동등록이 완료되었습니다.」

갱신 범위

✓ 알림 패널 수입·지출: afterLogsChanged → TodayStatsNotificationService.refreshFromDbIfEnabled()

✓ 앱 홈/목록: HomePage.requestRefresh() (기존 DB 콜백)

✗ 퀵등록 오버레이(shareData): 이번 범위 제외

파싱 실패·요금/출발지/도착지 미충족 → 저장·알림 없음 (조용히 스킵)

저장 경로: CallCardOcrParseService.saveLogToDatabase → DriveLogDatabase.insertOrUpdateDriveLog → afterLogsChanged

권한: READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE, DETECT_SCREEN_CAPTURE, POST_NOTIFICATIONS(완료 알림)
